# React Hands-On 1 – Student Profile Using Props

## Project Description

This project is a React-based Student Profile application created as part of React Hands-On 1.

The main objective of this project is to understand **React Props** by creating a reusable Student component and passing student details to it.

## Objective

Create a reusable Student component and pass the following student details using props:

- Name
- Roll Number
- Course
- College

The student information is displayed in a profile card.

## Technologies Used

- React.js
- JavaScript
- HTML
- CSS
- Vite

## React Concepts Used

- Functional Components
- Props
- Component Reusability
- JSX
- React Project Structure

## Expected Output

The application displays a Student Profile containing:

- Student Name
- Roll Number
- Course
- College

Example:

**Student Profile**

Name: Rahul  
Roll No: 101  
Course: BCA  
College: ABC College
